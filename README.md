# TXT 阅读器

纯前端的 TXT 在线听书 / 文字转语音阅读器。单个 `index.html`，无依赖、无后端，打开即用。

演示：https://www.bilibili.com/video/BV1WZrPBsEjw/

> 推荐使用 Edge 浏览器（语音库最全，中文在线语音质量最好）。

## 界面状态

| 状态 | 说明 |
| --- | --- |
| 导入页 | 首屏全屏大字界面，点击或拖入文件即导入 |
| 阅读页 | 正文区 + 顶部工具栏（悬停顶部唤出）+ 右侧章节目录（悬停右边缘唤出） |
| 专注模式 | 只显示当前朗读的那一句，居中放大显示 |

## 功能特点

- **智能编码检测** — BOM（UTF-8 / UTF-16LE / UTF-16BE）→ UTF-8 严格解码 → GB18030 回退，解决中文 TXT 乱码
- **句级切分** — 按 `。！？；!?;` 与换行切句，过短碎片自动并入上句，超长句（>200 字）按逗号/顿号再切
- **分块朗读** — 连续多句合并成一个 utterance（单块上限 600 字）并预排队，把合成延迟从「每句一次」降为「每块一次」
- **逐句高亮** — 通过 `onboundary` 的 `charIndex` 反推当前句，精确高亮到段落内的字符区间；无 boundary 事件时按语速估算兜底
- **自动降级** — 分块合成失败自动切换为逐句播放，单句仍失败则重试一次后提示更换语音/浏览器
- **专注模式** — 导入完成即自动开播并进入，只呈现当前句，适合听书
- **章节导航** — 正则识别「第X章/节/卷/集/部/篇/回」标题，支持目录跳转与上一章 / 下一章翻页
- **存档读档** — localStorage 保存句进度与语音偏好
- **多语速 / 多音色** — 0.5x ~ 3x（默认 1.5x）；语音按中文 / 英语 / 其他分组，优先选中含 `Xiaoxiao` 的中文语音
- **边缘悬停唤出** — 鼠标停在顶部 24px / 右侧 80px 区域 0.5 秒才展开面板，防误触；移出页面立即收起

## 使用方法

1. **导入** — 点击首屏任意位置选择文件，或直接把文件拖进窗口
2. **自动开播** — 导入后自动开始朗读并进入专注模式
3. **定位** — 单击段落选中起始句（不打断播放会续播），双击段落从该句立即开播
4. **章节** — 鼠标移到右边缘唤出目录，点击跳转；或用底部「上一章 / 下一章」按钮
5. **调节** — 顶部工具栏可切语音、调语速（切换后立即以新设置续播）
6. **存档** — 「存档」记录当前句进度，「读档」跳转回该句并开播
7. **换书** — 「重新导入」回到首屏

## 键盘快捷键（专注模式下）

| 按键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停（暂停保留当前句，恢复从该句继续） |
| `←` / `→` | 上一句 / 下一句 |
| `↑` / `↓` | 上一章 / 下一章 |
| `Esc` | 退出专注模式 |

## 支持的文件格式

`.txt` `.md` `.json` `.html` `.css` `.js` `.xml` `.csv` `.log`，以及任意 `text/*` 类型文件。

## 文本切分说明

1. 章节识别正则：`/^第[一二三四五六七八九十零〇百千万\d\s]{1,10}[章节卷集部篇回].+$/gm`
2. **正文按空行分段，段落内再按标点切句**，朗读单元与显示段落解耦（一个段落可含多句）
3. 未检测到章节时，上一章 / 下一章退化为按屏滚动翻页
4. 推荐使用 EmEditor 制作宏来整理 TXT

## 技术栈

- 纯 HTML / CSS / JavaScript，零依赖、零构建
- Web Speech API（`SpeechSynthesisUtterance` 语音合成）
- `localStorage`（键：`readingProgress`、`selectedVoice`）
- `FileReader` + `TextDecoder`（编码检测）

## 浏览器兼容性

需要支持 Web Speech API 的现代浏览器：Chrome / Edge 33+、Safari 7+、Firefox 49+。

> Firefox 与部分 Linux 环境可能没有可用的语音包或缺少 `onboundary` 事件；本项目已内置时间估算兜底，高亮与进度仍会前进。中文效果最佳的是 Edge。
